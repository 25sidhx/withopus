## 4. Tone & Voice

### Writing Style Rules
- Short sentences. One idea at a time.
- Lead with insight, not promotion
- Never explain the punchline — trust the reader
- Confident statements, not qualified opinions
- Warm but professional — not casual, not cold
- Always say less than you think you need to

### Sentence Style
- Prefer short over long
- Active voice always
- No passive constructions
- No filler phrases
- Paragraphs max 2-3 lines in social context

### Words / Phrases to USE
- craft, build, create, find, frame, shape
- cinematic, intentional, minimal, real, honest
- brand story, identity, visual language
- opus, masterpiece, work
- "we find" / "we build" / "we create"

### Words / Phrases to AVOID
- "one-stop solution"
- "taking your brand to the next level"
- "best-in-class"
- "affordable packages"
- "we are passionate about"
- "skyrocket your growth"
- "results-driven"
- "synergy", "leverage", "disruptive"
- Excessive emojis
- Exclamation marks in brand copy

### Example Lines (Approved Voice)
> "Most brands post content. We build identity."

> "Your brand already has a story. We just find the right frame."

> "Not every brand needs more content. Some just need better content."

> "Good content doesn't shout. It stays."

> "This is what happens when you stop trying to look like everyone else."

> "Every brand deserves an opus."

### Counter-Examples (Wrong Voice)
❌ "We help brands grow their social media presence with amazing content!"
❌ "Our team of experts will take your brand to the next level!!"
❌ "Affordable social media packages for small businesses 🚀🔥"
❌ "We are passionate about delivering results for our clients."

## 5. Visual Identity

### Core Direction
**Warm Cinematic Minimalism.**

Built on three pillars:
1. **Warmth** — amber-to-violet gradient palette, always warm-toned
2. **Texture** — grain/noise overlay that gives organic, non-digital depth
3. **Space** — intentional negative space that lets content breathe

### Design Philosophy
- Dark backgrounds. Almost always.
- One focal point per design. Never compete with yourself.
- The gradient is the hero — don't fight it with too many elements
- Grain texture on gradient backgrounds is mandatory for the brand signature look
- Compositions lean minimal — if an element doesn't add, it subtracts

### Layout Rules
- Generous padding/margins — minimum 80px safe zone on all content
- Left-aligned or centered text — never right-aligned
- Hierarchy: one headline, one subtext, one CTA maximum per frame
- Never more than 3 elements competing for attention

### Spacing Philosophy
- White (dark) space is not emptiness — it is intention
- If it feels too sparse, it's probably right
- Never fill corners for the sake of filling them

### Image Style
- Warm, directional lighting — golden hour aesthetic
- Slightly desaturated except warm tones
- Lifted blacks (not pure black in photography)
- Subtle film grain in all photos
- Dark backgrounds preferred
- Avoid: cold/blue-tinted, HDR, busy flat-lays, stock photo look

## 6. Color System

### Primary Palette

| Name | HEX | RGB | Usage |
|---|---|---|---|
| **Void Black** | `#0D0B14` | 13, 11, 20 | Primary background. All content lives on this |
| **Amber** | `#E8A034` | 232, 160, 52 | Gradient start. Accent highlights. CTA elements |
| **Burnt Orange** | `#D4431A` | 212, 67, 26 | Gradient mid-point. Warm energy |
| **Crimson** | `#7A1530` | 122, 21, 48 | Gradient transition. Deep warmth |
| **Deep Violet** | `#3D1155` | 61, 17, 85 | Gradient end. Mystery and depth |
| **Warm Cream** | `#F5F0E8` | 245, 240, 232 | All body text. Warmer than pure white |

### Secondary / UI Palette

| Name | HEX | Usage |
|---|---|---|
| **Surface Dark** | `#13101E` | Card backgrounds, secondary surfaces |
| **Surface Mid** | `#2A2535` | Borders, dividers, hover states |
| **Muted Text** | `#6B6478` | Secondary text, labels, captions |

### The Opus Gradient — Brand Signature
```
Direction: Left to right (90deg)
Stops: #E8A034 → #D4431A → #7A1530 → #3D1155
CSS: linear-gradient(90deg, #E8A034, #D4431A, #7A1530, #3D1155)
```
The gradient is not decoration. It IS the brand identity.

### Gradient Rules
- Only use the approved amber→orange→crimson→violet sequence
- Never use rainbow or multi-color gradients
- Never use cold/blue gradients
- Gradient applies to: wordmark, hero backgrounds, accent elements, highlight text
- Add grain/noise texture (5-8% opacity) over gradient backgrounds always

### Color Usage Rules

| Context | Background | Text | Accent |
|---|---|---|---|
| Instagram Posts | `#0D0B14` | `#F5F0E8` | Amber gradient |
| Reels / Video | Black + gradient bloom | White | Gradient overlay |
| Website | `#0D0B14` primary | `#F5F0E8` body | `#E8A034` amber |
| Documents / Proposals | White or cream | `#0D0B14` | Gradient header |
| Stories | Gradient bloom BG | White | Cream |

### Accessibility
- `#F5F0E8` on `#0D0B14` — contrast ratio ~14:1. Always use for body text.
- `#E8A034` on `#0D0B14` — use for accents/highlights only, not long-form text
- Minimum 4.5:1 contrast ratio for all readable text
- Never put gradient text on gradient backgrounds

## 7. Typography

### Primary Font — Satoshi
- **Use for:** All headings, logo wordmark, display text, hero copy
- **Source:** fontshare.com (free)
- **Weights:** 300 Light, 400 Regular, 500 Medium
- **Personality:** Clean geometric sans-serif, modern proportions, confident

### Secondary Font — Inter
- **Use for:** Body copy, captions, UI text, long-form reading
- **Source:** Google Fonts (free)
- **Weights:** 400 Regular, 500 Medium
- **Personality:** Highly legible, neutral, functional

### Type Hierarchy

| Level | Font | Weight | Size | Tracking | Usage |
|---|---|---|---|---|---|
| **H1 / Display** | Satoshi | 300 Light | 48–80px | -0.03em | Hero headlines |
| **H2 / Section** | Satoshi | 400 Regular | 28–36px | -0.02em | Section titles |
| **H3 / Sub** | Satoshi | 500 Medium | 18–22px | 0 | Sub-headings |
| **Body** | Inter | 400 Regular | 14–16px | 0 | Paragraphs, descriptions |
| **Caption / Label** | Inter | 400 Regular | 11–12px | +0.15em | Tags, labels (ALL CAPS) |

### Typography Rules
- Use Light (300) for large display text — heavy weights feel wrong for this brand
- Headlines: short and punchy — max 7-8 words
- Body: generous line-height 1.6–1.8
- Labels/tags: always uppercase with wide tracking
- Never mix more than 2 fonts in a single design
- Never use script, decorative, or handwritten fonts
- Never use bold (700+) for headings — too aggressive for the brand

## 8. Logo Guidelines

### Wordmark
The logo is the word **"opus"** in lowercase Satoshi, with the warm gradient applied left to right.

### Logo Versions

| Version | When to Use |
|---|---|
| **Gradient wordmark** (amber→violet on black) | Primary use — dark backgrounds |
| **White wordmark** (cream on gradient/colored BG) | On gradient backgrounds, dark images |
| **Dark wordmark** (black on cream/white) | Documents, proposals, light backgrounds |

### Clear Space
- Minimum clear space = height of the lowercase "o" on all sides
- No text, graphics, or elements enter this zone
- Minimum size: 80px wide (digital), 20mm wide (print)

### Logo Do's
- Use gradient version on dark backgrounds
- Use white version on gradient or colored backgrounds
- Maintain clear space at all times
- Use only approved color versions

### Logo Don'ts
- Do NOT add drop shadows or outer glows
- Do NOT place on busy, cluttered backgrounds
- Do NOT change font, weight, or letter spacing
- Do NOT use gradients other than the approved sequence
- Do NOT outline or stroke the letterforms
- Do NOT rotate, skew, or distort
- Do NOT add tagline directly attached to wordmark (keep separate)

## 9. Content Style

### Instagram Post Style
- Dark background always (`#0D0B14` or gradient bloom)
- Single clear message per post
- Headline: max 3 lines, Satoshi Light
- Tag/label: small uppercase above headline in amber
- Minimal elements — wordmark watermark bottom right only
- Safe zone: 80px padding all sides (1080x1080)

### Carousel Style
- One idea per slide — never cram
- Consistent background across all slides
- Slide 1: strong hook — statement or question
- Last slide: always CTA or brand moment
- Swipe trigger at the end of slide 1

### Reel / Video Style
- Slow, deliberate pacing — let frames breathe
- Warm color grade — amber shadows, desaturated cool tones
- Fade transitions — no hard cuts in brand content
- Text animation: fade up from below, no bounce/spring
- Grain texture overlay on all motion backgrounds
- Intro: wordmark fade in on gradient bloom

### Hook Style (Opening Line)
Strong Opus hooks are:
- Provocative statements: "Most brands post content. We build identity."
- Reframes: "Consistency isn't about posting more."
- Challenges: "Your content looks like everyone else's. Here's why."
- Single truths: "Good content doesn't shout. It stays."

Avoid: questions that beg ("Want to grow your brand? 👇"), hype openers ("🔥 This changed everything"), or over-promising hooks.

### Caption Style
- Line 1: The hook (standalone thought)
- Line 2-3: Expand with one supporting idea (optional)
- Final line: Soft CTA or closing statement — never pushy
- No hashtag dumps in caption body — move to first comment
- 3-5 relevant hashtags max if used

## 10. Do / Don't Rules

### ALWAYS DO
- Use `#0D0B14` as the primary background
- Apply grain texture to all gradient backgrounds
- Keep copy short — if it can be cut, cut it
- Use warm cream `#F5F0E8` for all body text
- Maintain generous negative space
- Apply the gradient consistently: amber → orange → crimson → violet
- Use Satoshi for headings, Inter for body
- Watermark with white "opus" wordmark on all content

### NEVER DO
- Use bright white `#FFFFFF` — use warm cream `#F5F0E8` instead
- Use rainbow, neon, or cold/blue gradients
- Use bold (700+) font weights in headings
- Crowd a design with multiple competing elements
- Use stock photo aesthetic
- Write long captions that explain everything
- Use exclamation marks in brand copy
- Add decorative elements that don't serve the composition
- Use comic or script fonts anywhere
- Use the gradient on light backgrounds (it needs darkness to work)

## 11. AI Instructions (Critical)

> **Read this section before generating any content for Opus.**

### General Rules for All AI Outputs
1. **Tone first.** Every output must sound like Opus — confident, minimal, cinematic. Re-read Section 4 before writing copy.
2. **Never be generic.** If the output could apply to any agency, rewrite it.
3. **Short is better.** Default to the shortest version that says the most.
4. **Dark aesthetic.** All visual prompts default to dark backgrounds with warm gradient tones.
5. **No buzzwords.** Reject any output containing: "one-stop solution", "next level", "passionate", "results-driven", "synergy", "affordable".

### For Copy / Caption Generation
- Write in short, punchy sentences
- Lead with insight or provocation, not features
- Never use more than 1 exclamation mark per piece of content
- Default caption length: 1-3 lines max for Instagram
- Do not add hashtag suggestions in the main caption body
- Always end with a statement, not a question or pushy CTA

### For Image / Visual Prompt Generation
Use these core elements in ALL visual prompts for Opus:
```
- Dark near-black background (#0D0B14)
- Warm gradient bloom: amber → burnt orange → crimson → deep violet
- Grain/noise texture overlay (organic, film-like)
- Minimal composition — one focal element
- Cinematic, warm lighting
- NO neon, NO rainbow, NO cold/blue tones
- NO busy compositions
- Font if text: clean geometric sans-serif, lowercase, cream/white
```

### For Strategy / Planning Output
- Always default to quality over volume
- Recommend retainer models over one-off projects
- Position Opus as premium — avoid "budget-friendly" framing
- Target audience: local D2C brands and businesses in India with ₹8-25k/month budget
- Focus on Instagram as primary platform first

### For Brand Voice Checks
Before finalizing any copy for Opus, ask:
- [ ] Is this shorter than it needs to be?
- [ ] Does this sound confident without being arrogant?
- [ ] Would a generic agency say this exact thing? (If yes, rewrite.)
- [ ] Is there warmth here, or does it feel cold/corporate?
- [ ] Does it pass the "lens flare, gradient, grain" visual test for imagery?
